# vibelink-demo-app

Deployed with [VibeLink](https://vibelink.dev) — The 1-Click Cloud & AI DevOps Gateway.

## 🚀 Live URL
[https://vibelink-demo-app.vibelink-dev.pages.dev](https://vibelink-demo-app.vibelink-dev.pages.dev)

## 🗄️ Database
- Provider: **Turso (libSQL)**
- Database: **`vibelink-demo-app-db`**

## 📦 Getting Started
1. Clone this repository:
   ```bash
   git clone <repo_url>
   cd vibelink-demo-app
   ```
2. Copy your `.env.local` with your `DATABASE_URL` and `TURSO_AUTH_TOKEN`.
3. Every time you push to the `main` branch, GitHub Actions will automatically compile and deploy to your live URL!
